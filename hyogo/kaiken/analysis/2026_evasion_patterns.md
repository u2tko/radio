## 1. 知事答弁の「4つの回避パターン」（`[事実]`）

| パターン | 該当件数（割合） | 平均字数 | 典型フレーズ・手口 | 時期推移（前半→中盤→後半） |
|---|---:|---:|---|---|
| **① 定型反復・既出扱い型** | **488件** (17.0%) | 189字 | 「これまで申し上げたとおり」「繰り返しになりますが」「認識に変わりはない」「ご意見として承っておきます」 | 14.8% → 18.4% → **18.6%**（通年最多） |
| **② 管轄分離・非認知シャットアウト型** | **157件** (5.5%) | **124字** | 「詳細は承知していない」「個別事案はコメント差し控え」「個人的な件・代理人へ」「担当部局に聞いて」「仮定の話」「最終的には司法」 | 5.4% → **6.8%** → 3.7%（中盤ピーク） |
| **③ 一般論・理念スリ替え型** | **146件** (5.1%) | 150字 | 「いずれにしましても〜すべきでない」「すべての皆様にお願いしたい」「民主主義ですから多様な意見が」「表現の自由は尊重しつつ」「法の趣旨を踏まえ適宜適切に」 | 4.0% → **6.0%** → 5.5% |

※1つの答弁に複数パターンが組み合わさるケースあり（重複カウント）。時期区分は前半（1〜4月）・中盤（5〜8月）・後半（9〜11月）。

### 各パターンの一次資料・代表例
- **① 定型反復・既出扱い型**: 新しい事実（百条委証言・公文書・法解釈の矛盾など）を提示されても、「先ほど来申し上げているとおり」「繰り返しになりますと同じ答えになりますんで」で新規の問いに応じない型（例：[2026-01-07.md](../2026/2026-01-07.md#L225)、[L983](../2026/2026-01-07.md#L983)、[2026-06-17.md](../2026/2026-06-17.md#L460-L492)）。
- **② 管轄分離・非認知シャットアウト型**: 最も短文で会話を閉じる型。丸尾県議訴訟の司法判決・ヘイトスピーチ動画・神社の看板・刑事告訴などに対し、「民事の個別事案」「詳細を承知していない」「個人的な件なので代理人へ」「趣旨がよくわからない」で入り口から遮断する（例：[2026-01-07.md](../2026/2026-01-07.md#L1217)、[2026-01-14.md](../2026/2026-01-14.md#L971)、[2026-02-04.md](../2026/2026-02-04.md#L503)、[2026-06-17.md](../2026/2026-06-17.md#L630)）。
- **③ 一般論・理念スリ替え型**: 「支持者の差別言動をやめさせてほしい」「公務中のスマホ使用は問題では」「3号通報の法解釈の整合性は」といった具体的追及に対し、「すべての皆様に誹謗中傷はすべきでない」「法の趣旨を踏まえて」「適宜適切に対応」と抽象的な道徳・一般論へ置き換える型（例：[2026-01-07.md](../2026/2026-01-07.md#L1103)、[2026-04-28.md](../2026/2026-04-28.md#L1136)、[2026-06-03.md](../2026/2026-06-03.md#L1133)、[2026-07-08.md](../2026/2026-07-08.md#L625)）。
- **④ 時間・手続き打切り／未来志向転換型**: 過去責任を問われた際に「これからしっかり」「道半ば」「前を向いて」と未来の話へずらす、あるいは後半（10〜11月）に急増した「不適切な表現が入っているため差し控える」「1時間過ぎておりますので」で質疑そのものを閉じる型（例：[2026-06-17.md](../2026/2026-06-17.md#L943)、[2026-08-19.md](../2026/2026-08-19.md#L762)、[2026-10-22.md](../2026/2026-10-22.md#L848)、[2026-11-04.md](../2026/2026-11-04.md#L777)）。

### B. 交絡チェック：「記者の違い」か「テーマの違い」か（`[検証・考察]`）

単純集計だけで「非加盟・フリー記者だから回避している」と結論づけるのを避けるため、**同一テーマ内での比較**および **1問目 vs 再質問の比較** を行った。

| 同一テーマ内での比較 | 記者クラブ加盟社（n / 平均字 / 指標 / 強回避） | 非加盟・フリー・赤旗（n / 平均字 / 指標 / 強回避） |
|---|---|---|
| **告発文書・公益通報** | n=258 / 162字 / **45.0%** / 28.3% | n=433 / **79字** / 41.6% / 32.3% |
| **会見運営・出禁・抗議** | n=93 / 241字 / **50.5%** / 21.5% | n=124 / **98字** / 40.3% / 25.8% |
| **選挙デマ・ヘイト差別** | n=43 / 173字 / 37.2% / 25.6% | n=166 / **88字** / 40.4% / 33.1% |
| **情報漏えい・不起訴** | n=42 / 207字 / 19.0% / **7.1%** | n=28 / **118字** / **46.4%** / **28.6%** |
| **財政・起債許可・用先債** | n=363 / 315字 / 17.1% / 1.9% | n=184 / **139字** / 21.7% / 5.4% |

1. **回避発動の主因は「誰が聞いたか」より「何を聞いたか」**
   - 告発文書・会見運営のテーマでは、記者クラブ加盟社に対しても **45〜50%の確率で回避指標が発動** しており、大手社であっても核心テーマでは同様に定型回避される。
2. **一方で、同一テーマ内でも非加盟・フリー・赤旗に対しては「極端な短文化」と「1問目からの強回避」が起きる**
   - どのテーマであっても、非加盟・フリー・赤旗への回答文字数は加盟社の **約4割〜半分（79〜139字）** に圧縮される。
   - 質問の順番で見ると、加盟社は **1問目の強回避が4.0%（平均331字）→ 再質問以降で10.8%（平均240字）** と段階的に回避が増えるのに対し、非加盟・フリー・赤旗は **1問目の段階から強回避 21.6%（平均115字）** と最初から定型・短文シャットアウトが発動している。
3. **検証上の留保（反論の先出し）**
   - 県公式議事録の `フリー記者A/B/C` は回ごとに発言順で振られる匿名記号であり、個人固定IDではないため合算集計としている。
   - また、非加盟・フリー側への回答が短い背景には、①1問目から結論や「イエス／ノー」を迫る短い詰問形式が多いこと、②会見後半（1時間近く経過した残り時間の少ない枠）で指名されることが多い構造的要因も重なっている点は差し引いて見る必要がある。
