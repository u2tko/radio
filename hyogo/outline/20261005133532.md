# 配信企画案（政策検証メイン）

## 1. 目的
- 配信者は斎藤元彦知事の県政及び斎藤知事周辺の支援者に批判的な立場をとる。
- 主目的は、日々の政策・予算・人事・会見・議会答弁を一次資料で検証し、説明責任を問うこと。
- 副目的は、告発文書問題で公的に確認された経過を風化させないこと。本体のネタにはしない。
- 「早期退陣」「再選阻止」は政治的主張だが、合わせて主張する。
- 私人攻撃、動員制裁、故人の私生活の詮索は目的に含めない。

## 2. 扱うもの／扱わないもの
主対象
- 知事の政策方針、予算、事業、条例、計画
- 人事、組織、契約、補助金、大型事業
- 会見・議会での説明、数値、根拠、時期
- 掲げた目標と、実施後の結果の差

副対象
- 県庁の公式対応、議会との関係
- 告発文書問題は、新しい公式発言・公式文書が出たときだけ本編で扱う

扱わない
- 人格、性格、動機の断定
- 家族、一般職員、一般支持者の特定
- 死因の断定、私的情報の再現
- ソースのない「周辺の不正リスト」

## 3. 配信の位置づけ
- 日常配信とは別アカウントのスペース。
- 名称：「#兵庫クリーンラジオ」
- 所要：10-12分前後。
- 頻度：ネタがある日だけ。毎日はやらない。
- 1回1点。政策の総論と個別事業を混ぜない。
- 配信の台本はやや配信口調寄り。少し崩すも、政治的な内容のため崩しすぎない。

## 4. 大原則
1. 人格ではなく、政策の目的・手段・費用・手続・結果・説明を見る。
2. 数字と原文を先に置き、評価は後に置く。
3. 事実／公式説明／他機関の指摘／報道／主張を混ぜない。
4. 誤りは次回冒頭で訂正する。
5. ソースが取れない日は休む。
6. 目標は「反論されないこと」ではなく「検証に耐えること」。

## 5. 政策検証の切り口
毎回このうち1つだけ使う。

1. 目的：何のための政策か。誰が受益者か。
2. 手段：その方法で目的に届く説明があるか。
3. 費用：総額、財源、単年か複数年か、県民負担の所在。
4. 手続：誰が、いつ、何に基づいて決めたか。議会・公開の程度。
5. 結果：目標値と実績。未公表なら「未公表」と言う。
6. 一貫性：過去の知事発言・公約・前年度方針とのずれ。
7. 説明：質問に数字で答えているか、評価でかわしているか。

告発文書問題を本編にする場合だけ、従来の「認定との対比」を使う。

## 6. 10分の型(10分程度の場合。配信枠に合わせて適宜変更する。)
1. 導入40秒：風化防止の1文＋本日の政策テーマ。
2. 対象2分：今日見る政策を1点に限定する。
3. 資料3分：方針文、予算書、会見録、会議録、実績値。
4. 検証3分：上の切り口のうち1つで照合する。
5. 結論40秒：今日言えること／言えないこと。主張は最後。

## 7. 冒頭1文の役割
- 毎回、告発文書問題の認定や被害等、N国党の知事選への関与等を1文置く。本文には入らない。
- 80〜120字。人格評と死因断定は入れない。
- その直後に、今日の政策テーマへ渡す1文を置く。

例  
「2025年3月、第三者委は告発者特定などを違法とし、パワハラを複数件認定した。今日見るのはその話ではなく、〔政策名〕の説明と数字である。」

## 8. オープニング、クロージング、スペースURL投稿用ポストテンプレート
オープニング、クロージング、スペースURL投稿用ポストのテンプレートは毎回以下の通りとする。
- オープニング  
  「みなさん、こんばんは。兵庫クリーンラジオ X月X日X曜日配信版です。この配信では、兵庫県政の正常化を願い、私が思ったことを中心に
  配信しています。」（以下、配信本体に入る）
- クロージング  
  （配信本体から引き継ぎ）「それでは、本日もお聞きいただきありがとうございました。兵庫クリーンラジオ、お別れの時間です。失礼します。」
- ポストテンプレート  
  【 #兵庫県政正常化 】#兵庫クリーンラジオ 「（ここに配信タイトルを入れる）」

## 9. 事実の階層（政策用）
1. ［事実］日付、金額、条文、会議決定、知事の原文
2. ［公式説明］県・知事がそう述べていること
3. ［外部指摘］監査、議会、国、報告書、統計
4. ［報道］裏が弱い場合は「報道」と明示
5. ［主張］配信者の評価。「私は〜と考える」

## 10. 運営
- 配信後に根拠資料名を投稿する。
- スペース中の質問は、資料で即答できなければ次回送り。
- 視聴者への約束は毎日更新ではなく、出すときは資料を添えること。

# 上司の指摘

## 2. 「私の主張・感想」の論理構造の検討

### (1) 「本来の課題が棚上げにされている」という主張について

- **事実誤認の可能性は低い**：斎藤知事をめぐっては、2025年3月の第三者調査委員会報告書で**パワハラの認定**と、**公益通報者保護法に違反する通報者探索**が指摘されています。また、2026年度予算編成においても、共産党県議団から「斎藤知事のもとではなく、新しい知事のもとで予算編成を行うべき」との申し入れが出されています。
- **論理の飛躍**：「特定外来生物対策への注力」と「財政健全化・告発文書問題の棚上げ」の間に**因果関係があるとは必ずしも言えません**。クビアカツヤカミキリ対策は2026年度当初予算で約9200万円が計上されており、これは県政の一部門の施策です。知事が複数の課題を並行して処理している可能性を否定できず、「棚上げ」と断定するには、予算配分や議会答弁の全体像を精査する必要があります。

### (2) 「やっている感がわかりやすい害虫退治にご執心」という評価について

- **主観的評価として妥当**：この表現は事実ではなく**評価・感想**であり、論理的な矛盾はありません。実際に「過度なパフォーマンス」「実効性や優先順位に疑問」との批判が存在します。
- **ただし「ご執心」の程度**：知事がクビアカツヤカミキリ対策にどれだけの時間とリソースを割いているかは、客観的データ（公務日程、予算執行率など）が示されない限り、「異常なまでに」という形容は**誇張の可能性**があります。

### (3) 「支持者に犬笛を吹いている」という主張について

- **比喩としての妥当性**：「犬笛」は特定の支持層にのみ届くメッセージを指す比喩です。斎藤知事の支持者と批判者の間でSNS上での激しい応酬が続いていること、支持者向けの発信が「犬笛」と評される事例があることは事実です。
- **論理の飛躍**：**「クビアカツヤカミキリの啓発」が直接的に支持者への犬笛として機能している**と立証するには、実際の支持者の反応や、知事の発言の文脈を分析する必要があります。「斎藤支持者に犬笛を吹いているとしか思えない」という表現は、**推測に基づく主張**であり、論理的な飛躍と言えます。ただし、**「そのように見える」という印象論としては理解可能**です。

## 3. 補足すべき批判的視点

ご提示の内容以外に、斎藤知事およびその周辺に対して批判的に考えられる視点を挙げます。
