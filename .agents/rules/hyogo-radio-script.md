# #兵庫クリーンラジオ 台本フォーマット・文体ルール

台本・原稿の作成や推敲を行う際は、直近の完成形に沿った以下の構成と文体を守る。

## 1. 分量とテーマ設定

- **1回1点**：政策の総論と個別事業などを混ぜず、1本の配信につき1つのテーマ・1つの切り口に絞る。
- **分量の目安**：参考資料を除く本文で **約3,400字（読み上げ約10分）** を目安とする（3,000〜3,800字程度の範囲で過不足なくまとめる）。

## 2. 定型フォーマット（上から順に配置）

1. **タイトル行（1行目）**
   - 形式：`#兵庫県政正常化 #兵庫クリーンラジオ 「＜サブタイトル＞」`
2. **オープニング挨拶（定型）**
   - 形式：`みなさん、こんばんは。兵庫クリーンラジオ、M月D日、X曜日の配信です。この配信では、兵庫県政の正常化を願って、私が思ったことを中心にお話ししています。`
3. **結論先行リード**
   - 今日のテーマを提示し、本編で言いたい結論・見立てを先に明示する（4〜5文程度）。
4. **本編（全4章構成）**
   - 見出し：`## 第1章 ＜見出し＞` 〜 `## 第4章 ＜見出し＞`
   - 各章とも、事実・引用・数字を先に置き、評価・違和感・主張を後ろに置く。
5. **おわりに（まとめ＋クロージング）**
   - 見出し：`## おわりに`
   - 導入文：`今日の話をまとめます。`
   - 各章に対応した **4項目の番号付き箇条書き**（`1.` 〜 `4.`）。
   - クロージング（定型）：`それでは、本日もお聞きいただき、ありがとうございました。兵庫クリーンラジオ、お別れの時間です。失礼します。`
6. **※参考資料**
   - 見出し：`※参考資料`（プレーンテキストまたは太字）
   - `- <出典名・日付・記事タイトル等>：<本文のどの記述・引用の根拠か、および留保事項>` を箇条書きで列挙する。
   - 会見の書き起こし、Grok等の検索経由で確認したSNS投稿、過去回（例：`20261115`）、AIとの壁打ちによる論点整理などを用いた場合は、その位置づけと「SNSの反応は受け止めの紹介であり事実根拠には使っていない」等の留保も明記する。

## 3. 文体・読み上げ適性

- **配信口調**：「です・ます」調の話し言葉寄りにする。ただし政治的テーマのため、砕けすぎない落ち着いたトーンを保つ。
- **呼称の統一**：「番組」ではなく **「配信」** を使う。
- **聞きやすさ**：一文を長くしすぎず、専門用語や行政用語は平易な言葉に言い換えるか補足を入れ、AI特有の硬い翻訳調・定型表現を避ける。
