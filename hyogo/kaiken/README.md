# 兵庫県知事記者会見 議事録アーカイブ（`hyogo/kaiken/`）

`#兵庫クリーンラジオ` の一次資料検証・発言推移の分析に用いる、兵庫県知事記者会見の公式議事録アーカイブです。

## フォルダ構成

```text
hyogo/kaiken/
├── README.md                  # 本ファイル（運用ルール・構成）
├── scripts/
│   └── convert_kaiken.py      # 公式HTML -> Markdown 変換スクリプト（Python標準ライブラリのみ）
├── 2026/                      # 兵庫県公式HPの議事録（一次資料）
│   ├── README.md              # 2026年 全会見の一覧表（回・開催日・種別・発表項目・公開状況）
│   ├── index.json             # 機械処理・検索用のメタデータ一覧
│   ├── 2026-01-07.md          # 各回の議事録マークダウン（YYYY-MM-DD.md）
│   └── 2026-05-26_hosei.md    # 同日に複数会見がある場合はサフィックスを付与
├── analysis/                  # 会見議事録の横断分析レポート（一次資料とは分離）
│   └── 2026_rhetoric_shift.md # 2026年 前半・中盤・後半のキーワード／アピール軸推移分析
└── external/                  # 外部団体・第三者による書き起こし等の補助資料（公式一次資料と分離）
    └── seijou-ni-modosu-kai/  # 任意団体「兵庫県政を正常に戻す会」の書き起こしPDF・差分メモ
```

## 一次資料としての取り扱いルール

1. **原文忠実性の維持**
   - 兵庫県公式サイト（[記者会見一覧](https://web.pref.hyogo.lg.jp/governor/cate3_603.html)）の議事録本文・発表項目・配布資料PDFリンク・動画リンク・公式注記を要約せず収録しています。
   - 分析メモや配信原稿（`hyogo/YYYY-MM/`）と混同しないよう、このフォルダ配下には一次資料の本文のみを置きます。
2. **公式議事録の性質に対する留保**
   - 兵庫県公式ページには「議事録の文章は、読みやすいよう、発言の趣旨を損なわない程度に整理しています。（事実と異なる場合は、適宜、訂正を行っています）」との断り書きがあります。
   - 厳密な言い回しやニュアンスを問題にする場合は、各ファイル冒頭の **動画URL**（公式YouTube）と必ず照合してください。
3. **未公開回・削除箇所の明示**
   - 開催直後で公式議事録が「（作成中）」の回は、`transcript_status: 作成中` として記録しています。公開後に再取得して差し替えます。
   - 県HP側で「不適切な表現が含まれていたため、動画・議事録については、該当箇所を削除」との注記がある回は、`has_redaction_notice: true` および公式注記欄に明記しています。
