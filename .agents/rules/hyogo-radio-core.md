# #兵庫クリーンラジオ 基本スタンス・事実規律

このリポジトリの `hyogo/` 配下で管理するラジオ配信原稿「#兵庫クリーンラジオ」に関する作業（調査、壁打ち、構成、執筆、推敲）では、以下の基本スタンスと規律を遵守する。

## 1. 番組の基本スタンスと目的

- **立場**：兵庫県知事・斎藤元彦氏の県政および関連する公的対応・言動を批判的に検証し、説明責任を問う立場をとる。
- **主目的**：日々の政策・予算・人事・会見・議会答弁を一次資料で検証し、県民・リスナーが事実関係と論点を理解できるようにすること。
- **副目的**：告発文書問題で公的に確認された経過を風化させないこと（ただし、新しい公式発言や公式文書が出た場合を除き、毎回の本編テーマにはしない）。
- **政治的主張の切り分け**：「早期退陣」「再選阻止」などの政治的主張は、事実認定と混ぜず、評価・主張として切り分けて述べる。
- **目標**：「反論されないこと」ではなく「検証に耐えること」を目指す。

## 2. 扱う範囲／扱わない範囲

### 扱う範囲
- 知事の政策方針、予算、事業、条例、計画、人事、組織、契約、補助金、大型事業
- 定例会見・議会・公式SNS等での説明、数値、根拠、時期
- 掲げた目標と実施後の結果の差、県庁の公式対応、議会・他自治体との関係
- 告発文書問題に関して公的に確認された経過（第三者委員会報告書、百条委員会報告書、消費者庁見解等）

### 扱わない範囲（禁止事項）
- 知事や関係者の**人格・性格・内心の動機の断定**
- **家族、一般職員、一般支持者の特定**や私人攻撃、動員制裁
- **故人の死因の断定**、私生活・私的情報の詮索や再現
- ソースのない疑惑や「周辺の不正リスト」、集団へのレッテル貼り

## 3. 事実確認・留保の規律

1. **一次資料を最優先する**：県の公式資料、予算書、議事録、会見録・会見発言、第三者委等の報告書を優先し、数字と原文を先に置き、評価を後に置く。
2. **未確認事項は留保する**：県公式の会見録が未公開の場合や、欠席理由・実績値などが公表されていない場合は、推測で埋めず「未公表」「報じられていない」「書き起こしに基づく」等と明示する。ソースが取れないテーマは見送る。
3. **批判対象側に有利な前提や異論も確認する**：支持率の回復推移、副知事の代理出席自体は珍しくない点、選挙区ごとの固有事情など、対象側に有利な事実や一般的な慣行も先に事実として認めたうえで、それでも残る矛盾や論点を立てる。
4. **誤りの訂正**：事実誤認が判明した場合は、次回冒頭等で速やかに訂正する前提で扱う。
5. **ディレクトリの扱い**：`hyogo/outline/` は初期テンプレート・参考資料として保持し、新規原稿は `hyogo/YYYY-MM/YYYYMMDD.md` 形式で管理する。
