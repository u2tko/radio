# AI書き起こしドラフト（`hyogo/kaiken/draft/`）

兵庫県公式の記者会見議事録が公開される前（`作成中` の段階）に、AIによる会見文字起こしドラフトを保管し、`#兵庫クリーンラジオ` のネタ出し・論点整理に活用するためのフォルダです。

## 取り扱いルール（公式一次資料との分離）

1. **一次資料との明確な分離**
   - ここには公式議事録公開前の **AI文字起こしドラフト** のみを置きます。県公式HPの一次資料（[`../2026/`](../2026/README.md)）とは混ぜないでください。
2. **誤認識・留保の前提**
   - AI文字起こしには、固有名詞の誤変換・聞き間違い・話者誤認が含まれる可能性があります。
   - ネタ出し・壁打ちの段階では活用しつつ、実際の配信原稿（`hyogo/YYYY-MM/`）に落とし込む際は、**公式動画（YouTube）での確認**および**「AI書き起こし・視聴確認に基づく（公式議事録未公開）」旨の留保注記**（`※参考資料` 欄）を徹底してください。
3. **公式議事録公開後の扱い**
   - [`../2026/`](../2026/README.md) に公式議事録が公開された後は、一次資料として公式議事録を優先して参照してください。

## ファイル命名規則

- 原則として開催日ベースで `YYYY-MM-DD.md`（または `.txt`）とします。
- 同日に複数回見がある場合は、`YYYY-MM-DD_hosei.md` のように [`../2026/`](../2026/README.md) と揃えたサフィックスを付与してください。
