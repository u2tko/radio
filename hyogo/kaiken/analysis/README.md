## 記事（配信原稿）に回す際の注意点

1. **原文リンクの確認**: 各レポート内の日付・行番号リンクから [`../2026/`](../2026/README.md) の公式議事録原文を開き、前後の文脈を確認したうえで引用する。
2. **情報階層の切り分け**: レポート内の `[事実]`（数値・原文）と `[考察・仮説]`（見立て）を混ぜず、配信原稿でも話し言葉で明確に言い分ける。
3. **留保の先出し**: 各項目に記載されている「検証上の留保・想定反論」を、本論の前にフェアに押さえてから論点を立てる。
