# `#兵庫クリーンラジオ` アーカイブ横断分析・索引化ワークフロー

このスキルは、`hyogo/YYYY-MM/` に蓄積されたラジオ配信原稿を横断的に分析・棚卸し・過去回検索するための手順を定める。

---

## 基本原則

- **テキスト根拠の徹底**: すべての集計・要約・引用はリポジトリ内の実ファイルに基づくこと。推測で過去回の内容を補完しない。
- **分析者としての中立な記述**: 分析レポートでは「原稿内で配信者が何を検証・主張しているか」を客観的に整理して記述する。
- **ポータブルな相対リンク**: `hyogo/analysis/` 配下にレポートを保存する際は、`../2026-11/20261126.md` のような相対パスリンクを用い、ローカルPC固有の絶対パス（ユーザー名を含むパス等）を含めない。

---

## 主な分析タスクと手順

### A. 棚卸し・変遷レポートの更新（新月・新規原稿追加時）

1. 必要に応じて `git pull` で最新原稿を取り込む（未コミットのローカル編集がある場合は先に確認する）。
2. `hyogo/analysis/` の既存レポートを確認し、前回集計以降に追加されたファイルだけを差分抽出する（全件の再読み込みを避けて効率化する）。
3. 追加分について以下を抽出・集計する：
   - ファイル名、配信日、タイトル、空白除き文字数（推定尺＝350字/分）
   - テーマ分類、検証の切り口・主な論点（1〜2文）
   - 構成・フォーマットの変化、主要キーワード出現頻度
4. 既存レポートを更新するか、新しい期間レポートを `hyogo/analysis/` に保存する。

### B. 過去回検索・引用リンク抽出（「前にこの件いつ話した？」）

1. キーワード（人物名、定型語、政策名、日付など）で `hyogo/2026-*/` を横断検索する。
2. ヒットしたファイルを読み込み、以下の形式で返す：
   - ファイルパス・配信日・タイトル
   - その回での該当箇所の要旨（どの文脈で何を検証したか）
   - 新規原稿の `※参考資料` にそのまま貼れる参照文（例：`YYYYMMDD（本配信の過去回）：〇〇の経緯`）

### C. テーマ別深掘り・未回収論点の発掘

1. 対象テーマに関連する全回を時系列に並べ、「主張の一貫性」「切り口の変化」「未確認・未公表のまま残っている事実（例：予算執行実績、納期、続報待ちの案件）」を抽出する。
2. 必要に応じて次回企画の切り口候補（1回1点・対比軸つき）を提案する。
